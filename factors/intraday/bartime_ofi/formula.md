# Formula

For stock \(s\) at the current minute \(t\):

\[
\operatorname{bartime\_ofi}_{s,t}
=
\frac{B_{s,t}-S_{s,t}}{B_{s,t}+S_{s,t}},
\qquad B_{s,t}+S_{s,t}>0
\]

where \(B_{s,t}\) and \(S_{s,t}\) are the raw positive active buy
and active sell amounts for minute \(t\). Both missing amounts are treated as
zero.

The value uses only the current row—there is no cumulative sum, rolling window
or future shift—and is emitted at 09:59, 10:29, 11:29, 13:29 and 14:29.

Python is the golden reference and explicit fallback. The production DDB query
is generated by `core.ddb_intraday_queries.discovery_v1_factor_script` with
factor name `bartime_ofi`.
