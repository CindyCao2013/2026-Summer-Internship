# active_buy_shock — Discovery v1 Report

## Implementation

Status: package implementation complete; live DDB and backtest parity pending.

The package delegates both reference and production calculations to
`factors.intraday.discovery_v1`. DDB scripts are generated by
`core.ddb_intraday_queries.discovery_v1_factor_script`; no shared production or
evaluation files are modified by this package.

## Frozen contract

- Value: current adjusted active-buy amount minus its prior-20-bar mean, divided
  by the prior-20-bar sample standard deviation
- Baseline: positive one-bar shift; current bar excluded
- Minimum history: 10 prior bars
- State boundary: `Symbol, Date` session reset
- Signal times: 09:59, 10:29, 11:29, 13:29, 14:29
- Invalid/zero historical standard deviation: no signal

## Validation

Non-live tests cover:

1. adjusted-amount formula and sample-standard-deviation semantics;
2. future-bar mutation invariance;
3. session reset and minimum-history behavior;
4. exact five-bartime output policy;
5. positive-shift, ordered-session DDB script contract;
6. enabled production-registry dispatch to the shared DDB implementation.

Live tests are intentionally gated by `RUN_DDB_TESTS=1`. Acceptance requires:

- formula maximum absolute difference no greater than `1e-10`;
- cross-sectional Spearman no lower than `0.999`;
- exact signal keys and bartimes;
- unchanged-backtest IC, ICIR, decile/H-L Sharpe, signal universe, and turnover
  parity through `run_backtest_parity.py`.

No empirical alpha or production-readiness claim is made until those live gates
and the intended out-of-sample research protocol pass.
