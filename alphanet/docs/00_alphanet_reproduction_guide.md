# AlphaNet 因子挖掘神经网络 — 完整复现指南

> 本文档基于华泰证券研究报告《AlphaNet：因子挖掘神经网络》（2020年6月14日）整理，补充了修改后的测试协议（10层分组、超额收益、单边万分之7.5交易成本），用于指导端到端复现。

---

## 1. 模型核心思想

AlphaNet 是一个**端到端**的深度学习模型，直接使用个股的**原始量价数据**（日频）预测未来收益率，**自动挖掘因子**并**加权合成**，避免人工特征工程和信息损失。

- 借鉴**遗传规划**的思想，将多种时序运算符封装为**自定义网络层**，构成特征提取层。
- 仿照**CNN**的数据组织形式，将股票历史窗口数据整理为**二维“数据图片”**。
- 使用**批标准化（BN）** 统一特征量纲。
- 最终通过**全连接层**合成因子，以 MSE 为损失函数回归未来收益率。

---

## 2. AlphaNet 网络结构详解

### 2.1 数据输入

将每只股票过去 **T 个交易日**（`T=30`）的 **9 个量价序列**拼接成一张 `9 × T` 的“数据图片”。

**9 个特征维度**（按行排列）：
1. `return1` （日收益率，由后复权收盘价计算）
2. `open`
3. `close`
4. `high`
5. `low`
6. `vwap` （成交量加权平均价）
7. `volume`
8. `turn` （换手率）
9. `free_turn` （自由流通股换手率）

每个截面期，对每只股票可得到一张图片，标签为该股票 **未来 m 天的标准化收益率**（m=10 或 5）。样本内共 N 只股票，则构成 N 个 `(9, 30)` 的输入张量及对应的标签向量。

**排序无关性**：特征维度的排列顺序任意，因为自定义算子会对所有特征进行交叉运算，不依赖固定相邻关系。

---

### 2.2 特征提取层

特征提取层是 AlphaNet 的核心，包含以下**自定义运算网络层**（每个运算后均紧跟一个 **Batch Normalization 层**）：

| 运算符 | 定义 |
|--------|------|
| `ts_corr(X, Y, d)` | 过去 d 天 X 序列与 Y 序列的相关系数 |
| `ts_cov(X, Y, d)` | 过去 d 天 X 与 Y 的协方差 |
| `ts_stddev(X, d)` | 过去 d 天 X 序列的标准差 |
| `ts_zscore(X, d)` | (X - mean(X, d)) / stddev(X, d) |
| `ts_return(X, d)` | (X / delay(X, d)) - 1 |
| `ts_decaylinear(X, d)` | 过去 d 天的线性衰减加权平均（权重 d, d-1, ..., 1） |
| `ts_mean(X, d)` | 过去 d 天的均值 |
| `ts_max(X, d)` | 过去 d 天的最大值 |
| `ts_min(X, d)` | 过去 d 天的最小值 |
| `ts_sum(X, d)` | 过去 d 天的总和 |

**工作机制（以 `ts_corr` 为例，设 d=10）**：

- 在**时间维度**上以步长 `stride=10` 滑动窗口（类似 CNN 卷积），每个窗口产生一个相关系数值。
- 在**特征维度**上，对所有可能的 `(X, Y)` 组合进行遍历（共 9×9=81 对），不受局部感受野限制。
- 输出为一张“特征图”，尺寸为 `(特征组合数, 时间窗口数)`，可继续输入池化层或直接展平。

**说明**：`stride` 可调，V1 中 `stride=10` 使得时间窗口不重叠，降低计算量。每个自定义层后接 BN，使得不同运算符输出的特征在量纲上可比。

---

### 2.3 池化层

池化层对特征提取层的输出进行“模糊化”，类似 CNN 中的池化操作。AlphaNet-V1 使用以下三种池化方式，每个池化窗口大小 `d=3`，步长 `stride=3`（即不重叠）：

- `ts_mean(X, 3)`：3 个时间步的均值池化
- `ts_max(X, 3)`：3 个时间步的最大池化
- `ts_min(X, 3)`：3 个时间步的最小池化

池化层同样后接 BN 层，池化结果展平后输入全连接层。

**嵌套运算**：池化层可与特征提取层嵌套，例如 `ts_mean(ts_corr(open, high, 10), 3)`，实现更深层次的特征提取（V1 中仅使用单层特征提取+池化，但结构允许嵌套）。

---

### 2.4 全连接层

特征提取层和池化层的输出经过展平（flatten）后，接入一个**单隐层全连接网络**：

- **隐藏层**：30 个神经元，激活函数 **ReLU**，Dropout 率 **0.5**（用于正则化）
- **输出层**：1 个神经元，无激活函数（直接输出预测值）

**权重初始化**：`truncated_normal`（截断正态），以减小极端初始值。

**损失函数**：均方误差（MSE），即预测的标准化收益率与真实标准化收益率之间的平方差。

**优化器**：RMSprop，学习率 0.0001。

**训练**：使用 `batch_size=1000`，并采用 **early stopping**（patience=10，基于验证集损失）。

## 3. 数据准备与模型训练流程

### 3.1 数据准备

- **股票池**：全 A 股，剔除 ST、*ST、PT 股票，剔除每个截面期下一交易日涨跌停或停牌的股票。
- **输入数据**：上述 9 个量价序列，每个截面期取过去 30 个交易日的数据，标准化为 `(9, 30)` 图片。
- **预测目标**：个股未来 m 个交易日的收益率（m=10 或 5），并做 **截面标准化**（减去均值除以标准差）使其量纲统一。
- **时间区间**：2011‑01‑31 至 2020‑05‑29。
- **样本内窗口**：每次训练使用过去 1500 个交易日的数据，**每隔两天采样一次**（即每 3 个交易日取一个截面），以减少序列相关性。
- **训练/验证集划分**：按时间顺序 1:1 划分（训练集在前，验证集在后）。

### 3.2 模型构建细节（AlphaNet‑V1）

| 组件 | 具体参数 |
|------|----------|
| **特征提取层** | 10 种自定义运算（`ts_corr`, `ts_cov`, `ts_stddev`, `ts_zscore`, `ts_return`, `ts_decaylinear`, `ts_mean`, `ts_max`, `ts_min`, `ts_sum`），d=10，stride=10。每种运算后接 BN 层。特征提取结果同时展平（直连全连接层）和送入池化层。 |
| **池化层** | `ts_mean`, `ts_max`, `ts_min`，d=3，stride=3，后接 BN，展平后送入全连接层。 |
| **全连接层** | 隐藏层 30 个神经元，ReLU，Dropout 0.5；输出层 1 个神经元。 |
| **优化器** | RMSprop，lr=0.0001 |
| **损失函数** | MSE |
| **Batch size** | 1000 |
| **Early stopping** | patience=10（验证集损失不改善则停止） |
| **重复实验** | 因神经网络随机性，上述流程独立运行 10 次，取平均结果。 |

### 3.3 滚动训练与预测

- 从 2011‑01‑31 开始，**每半年**重新训练一次模型（即每 6 个月滚动更新样本内数据）。
- 每次训练使用**过去 1500 个交易日**的数据，训练集和验证集按时间 1:1 划分。
- 在样本外截面期，使用最新训练的模型预测未来 m 天收益率，该预测值即为**合成因子**。
- 重复 10 次不同随机种子，最终因子为 10 次预测的均值。

### 3.4 组合构建与回测（原始报告）

报告测试了两种调仓周期：10 天和 5 天。

- **单因子测试**：IC 分析、分 5 层测试（等权重，TOP/BOTTOM 多空）。
- **增强策略**：构建行业市值中性的中证 500 增强组合，通过组合优化（最大化因子暴露，控制行业/市值中性，个股权重偏离上限，双边换手率 ≤30%），交易成本为单边千分之二。

## 4. 修改后的测试协议（本复现指南采用）

以下为本项目采用的**修改后测试标准**，旨在更严格地评估因子效果，并与现有因子库一致。

### 4.1 分 10 层测试（替代原 5 层）

在每个截面期，将合成因子的值从大到小排序，等分为 **10 组**（若股票总数不能被 10 整除，采用近似等分）。每组内个股等权配置。基准为**全市场等权组合**（即所有可交易股票的等权收益）。

**关键指标**：
- **每层年化超额收益率**（相对全市场等权基准）。
- **多空组合（H-L）**：第 1 层（Top）减去第 10 层（Bottom）的收益率序列，计算年化收益率、夏普比率、最大回撤等。
- **分层单调性**：检查各层超额收益是否严格单调递减。

### 4.2 收益统一为超额收益（Excess Return）

所有分层组合收益均表示为 **相对于全市场等权基准的超额收益**，剔除市场整体波动影响，便于跨期比较。超额收益序列通过 `组合收益 - 基准收益` 获得。

### 4.3 交易成本与仓库对齐：单边万分之 7.5

为与本仓库 L2 / `candidate_pool_v1` 回测口径一致，测试中**单边交易成本设为万分之 7.5**（7.5 bps，0.075%，代码中 `0.00075`）。换仓时买入和卖出均按该费率扣除，双边合计万分之 15（15 bps，0.15%）。

不要写成 7.5‰。‰ 表示千分之，7.5‰ = 0.75%，比本口径大 10 倍。

- 对于分层测试：换仓时，新持仓与旧持仓的差异部分按单边万分之 7.5 扣除成本。
- 对于增强策略：优化器目标函数考虑成本，且每次调仓双边换手率仍限制 ≤30%。

### 4.4 合成因子中性化处理

所有测试均针对 **五因子中性化后的合成因子** 进行，以剥离常见风险因子的影响：

- 行业（申万一级）
- 市值（对数市值）
- 动量（过去 m 日收益率，m 与调仓周期一致）
- 波动率（过去 m 日收益率波动率）
- 换手率（过去 m 日平均换手率）

中性化方法：截面回归，取残差作为新因子值。

## 5. 单因子 IC 测试（修改后）

- **回测区间**：2011‑01‑31 至 2020‑05‑29（可扩展）。
- **截面期**：每隔 m 个交易日（m=10 或 5）。
- **计算方式**：在每个截面期，计算中性化后因子值与下 m 个交易日收益的 **RankIC**（Spearman 相关系数）。
- **报告指标**：RankIC 均值、标准差、ICIR（均值/标准差）、IC>0 占比。

---

## 6. 分 10 层测试（修改后）

**步骤**：

1. 在每个截面期，将中性化后因子值排序，等分为 10 组（G1~G10，G1 为因子最高组）。
2. 每只股票分配等权重（组内等权）。
3. 持有至下一个截面期（m 天后），计算组合收益（扣除交易成本，单边万分之 7.5）。
4. 基准为全市场等权组合。
5. 计算各组的超额收益序列。
6. 计算 G1 和 G10 的多空组合（H-L）收益，并统计年化收益率、夏普比率、最大回撤、胜率等。

## 7. 增强策略回测（修改后）

构建**行业市值中性**的增强组合，对标中证 500（或全 A），并通过组合优化权重。

**优化目标**：最大化组合的合成因子暴露（即加权平均因子值）。

**约束条件**：

- 行业权重 = 基准行业权重（如中证 500 行业权重）
- 市值权重 = 基准市值权重（中性）
- 个股权重偏离基准（等权或市值加权）不超过设定上限（如 0.5%, 1%, 1.5%, 2%）
- 双边换手率 ≤ 30%
- 个股不可做空，权重介于 0~5% 等。

**交易成本**：单边万分之 7.5（7.5 bps，`0.00075`）。

**回测指标**：年化收益率、波动率、夏普比率、最大回撤、年化超额收益、信息比率、Calmar 比率、换手率等。

**基准**：中证 500 指数。

**结果呈现**：展示不同个股权重偏离上限下的绩效，并绘制超额收益曲线。

## 8. 模型可解释性分析（SHAP）

使用 **SHAP** 值对 AlphaNet‑V1 进行解释：

- 选取最新一次训练的模型（如 2020‑01）。
- 对展平后的所有特征（来自特征提取层和池化层）计算 SHAP 值。
- **特征重要性**：以 |SHAP| 均值排序，展示前 20 个重要特征。
- **特征方向**：通过 SHAP 依赖图判断特征与预测目标的关系（线性正向、线性反向或非线性）。

**用途**：帮助理解模型学到了哪些运算符和原始数据的组合，可为后续人工因子构建提供启发。

实现一个自定义生成器，每次返回一个 batch 的 `(9, 30)` 图片和对应的未来收益率标签。需注意：

- 对每个截面，所有股票的图片堆叠成 batch。

### 9.3 网络构建

```python
from tensorflow.keras import Model, Input
from tensorflow.keras.layers import Concatenate, Flatten, Dense, Dropout, BatchNormalization

input_img = Input(shape=(9, 30))
# 特征提取层：应用所有算子，每个输出接 BN
extracted_features = []   # 每个元素是 (batch, num_combos, num_windows)
for op in ops:
    out = op(input_img)   # 自定义层
    out = BatchNormalization()(out)
    extracted_features.append(out)

# 池化层：对每个提取特征应用池化，接 BN
pooled_features = []
for feat in extracted_features:
    for pool_op in [ts_mean, ts_max, ts_min]:
        p = pool_op(feat, d=3, stride=3)
        p = BatchNormalization()(p)
        pooled_features.append(p)

# 展平所有特征（包括提取层和池化层的输出）
flat = Concatenate(axis=-1)([Flatten()(f) for f in extracted_features + pooled_features])

# 全连接层
hidden = Dense(30, activation='relu')(flat)
hidden = Dropout(0.5)(hidden)
output = Dense(1)(hidden)

model = Model(inputs=input_img, outputs=output)
model.compile(optimizer=tf.keras.optimizers.RMSprop(0.0001), loss='mse')
```

### 9.4 滚动训练与预测

每半年执行一次：

1. 确定训练区间（过去 1500 天）和验证区间（后 750 天）。
2. 从数据中抽取对应截面，构造图片和标签。
3. 训练模型，early stopping 基于验证损失。
4. 用训练好的模型预测当前样本外截面期的因子值。
5. 存储因子值用于后续分析。

重复 10 次不同随机种子，最终因子为 10 次预测的平均。

## 10. 注意事项与风险

- **随机性**：神经网络初始化和训练过程有随机性，必须多次重复实验取平均结果，结论才稳定。
- **过拟合**：使用 Dropout、early stopping、有限的隐藏层大小（30 个神经元）和较少的层数来防止过拟合。
- **数据泄露**：滚动训练保证未来数据不用于当前模型训练；标准化标签时使用截面统计，不会引入未来信息。
- **计算成本**：训练 10 次 × 每半年一次，耗时较长，建议使用 GPU 加速。
- **交易成本**：单边万分之 7.5（7.5 bps），与仓库其余因子回测一致。勿与千分之 7.5（0.75%）混淆。

---

## 11. 后续改进方向

1. **引入更多原始特征**（如分钟级数据、订单簿数据），并适配 AlphaNet 的数据输入格式。
2. **加深网络**：允许特征提取层和池化层的嵌套（多层运算符），构建更深层次的因子。
3. **引入注意力机制**：让模型自动聚焦重要时间点或特征组合。
4. **使用更先进的优化器**（如 Adam）和正则化技术（如权重衰减）。
5. **扩展预测目标**：尝试不同周期（如 1 天、20 天）或不同风险调整后的收益。
