# AlphaNet 进阶复现指南：v2 与 v3 结构与特征优化

> 本文档基于华泰证券研究报告《再探 AlphaNet：结构和特征优化》（2020年8月24日）整理，补充修改后的测试协议（10 层分组、超额收益、单边万分之 7.5 交易成本），用于指导 AlphaNet‑v2 和 AlphaNet‑v3 的完整复现。

---

## 1. 为什么要升级 AlphaNet？

原版 AlphaNet‑v1（2020.6.14 报告）在全 A 股和中证 500 成分股上表现良好，但在 **2019 年下半年之后出现明显回撤**。为改善这一问题，华泰金工从**网络结构**和**输入特征**两个维度进行优化，先后推出 v2 和 v3：

- **AlphaNet‑v2**：在 v1 基础上扩充比率类特征、将池化层+全连接层替换为 LSTM、调整训练/验证集划分。
- **AlphaNet‑v3**：进一步在 v2 基础上增加两层特征提取层（回看窗口 5 天）并将 LSTM 替换为 GRU 以减少参数。

测试结果显示，v2 在全 A 股和中证 800 成分股中全面优于 v1；v3 在中证 500 中略优于 v2。

## 3. 核心改进细节

### 3.1 扩充比率类特征（v2 和 v3）

在原始 9 个量价序列的基础上，新增以下 6 个比率特征，组成 15×30 的“数据图片”：


| 新增特征              | 计算公式           | 经济含义          |
| ----------------- | -------------- | ------------- |
| `close/free_turn` | 收盘价 / 自由流通股换手率 | 价格与自由流通换手的比值  |
| `open/turn`       | 开盘价 / 换手率      | 开盘价与总换手的比值    |
| `volume/low`      | 成交量 / 最低价      | 交易量与最低价的比值    |
| `vwap/high`       | 成交量加权均价 / 最高价  | 平均成交价相对最高价的水平 |
| `low/high`        | 最低价 / 最高价      | 日内价格区间相对位置    |
| `vwap/close`      | 成交量加权均价 / 收盘价  | 平均成交价相对收盘价的偏离 |


这些比率特征在遗传规划挖掘的因子中被证明具有分层效果（报告中图 8、图 9），有助于提升模型表现。

### 3.2 用 LSTM/GRU 替代池化层和全连接层（v2/v3）

- **原 v1**：特征提取层输出后经过 3 个时序池化（mean/max/min）再展平，然后接全连接层。这种方式对时序信息做了“模糊化”，丢失了顺序信息。
- **v2 改进**：将池化层和全连接层替换为一个 **LSTM 层**（time_step=3），直接对提取的特征序列（每个时间步对应一个特征向量）进行建模。LSTM 能更好地捕捉时序依赖，因为特征提取层输出的特征仍然保留时间顺序（见图 11）。
- **v3 改进**：由于 v2 中 LSTM 参数较多，v3 采用 **GRU**（门控循环单元）替代 LSTM，减少约 25% 的参数，性能相近。同时 v3 使用 **两个 GRU 层**：第一个处理 time_step=3 的特征，第二个处理 time_step=6 的更大窗口，以捕捉不同尺度的时序模式。

### 3.3 训练/验证集划分（v2/v3）

- **v1**：训练集:验证集 = 1:1（按时间先后，训练在前，验证在后）
- **v2/v3**：改为 **4:1**。验证集比例减少，相当于用更多数据训练，且验证集更贴近近期样本，有利于模型适应最新市场环境（报告中指出 v1 在 2019 下半年后表现不佳，部分原因可能是验证集过大导致模型偏向中期规律）。

### 3.4 特征提取层扩展（v3 特有）

- v3 在 v2 的基础上增加了**第二层特征提取**，包含回看窗口 **d=5** 的 6 种算子（ts_corr, ts_cov, ts_stddev, ts_zscore, ts_return, ts_decaylinear），stride=5。
- 这样模型可以同时捕获中期（10 天）和短期（5 天）的量价关系，丰富了特征多样性。
- 注意：v3 仍只使用 6 种算子（而非 v1/v2 的 10 种），因为研究者认为这 6 种在实验中已足够，且减少计算量。

## 4. 数据准备（与 v1 相同，但特征维度增至 15）

- **股票池**：
  - 全 A 股（测试 v2）
  - 中证 800 成分股（测试 v2）
  - 中证 500 成分股（测试 v3 与 v2 对比）
- **剔除**：ST、*ST、PT，以及每个截面期下一交易日涨跌停或停牌的股票。
- **输入特征**：上述 15 个量价序列，每个截面取过去 30 个交易日的数据（即 `15 × 30` 图片）。
- **预测目标**：个股未来 **10 个交易日**的标准化收益率（截面 z‑score）。
- **回测区间**：2011‑01‑31 至 2020‑07‑31。
- **样本内窗口**：过去 1500 个交易日，每隔两天采样一次（减少序列相关）。
- **训练/验证划分**：按时间 4:1（训练:验证）。

---

## 5. 训练与预测流程（滚动）

- 从 2011‑01‑31 开始，**每半年**滚动训练一次。
- 每次训练使用过去 1500 个交易日的样本内数据，按 4:1 分割训练/验证集。
- 训练停止条件：early stopping（patience=10）基于验证集 MSE。
- 在样本外截面期，用最新训练的模型预测未来 10 天收益率。
- 为克服随机性，独立训练 **10 个模型**（不同随机种子），预测结果取**等权平均**作为最终的合成因子。

## 6. 测试协议（与前一文档一致，沿用修改后标准）

> 以下为本文档采用的标准，与先前 AlphaNet 复现指南中的修改一致，用于横向对比。

### 6.1 单因子 IC 测试

- 中性化：对合成因子进行**五因子中性化**（行业、市值、10 日收益率、10 日波动率、10 日换手率），取回归残差。
- 计算 RankIC：每 10 个交易日截面，因子值与未来 10 天收益的 Spearman 相关系数。
- 报告：RankIC 均值、标准差、ICIR（均值/标准差）、IC>0 占比。

### 6.2 分 10 层测试（替代原 5 层）

- 在每个截面，将中性化后因子排序，等分为 **10 组**（G1~G10，G1 最高）。
- 组内等权重，持有至下一截面（10 天后）。
- **交易成本**：单边 **万分之 7.5**（7.5 bps，`0.00075`）。
- 基准：**全市场等权组合**（该股票池内全部股票等权）。
- 计算各组年化超额收益、多空（H‑L）年化收益、夏普比率、最大回撤等。
- 单调性：考察 G1 至 G10 超额收益是否递减。

### 6.3 增强策略回测

- 目标：构建相对于基准指数（中证500 或中证800）的**行业、市值中性**增强组合。
- 优化：最大化组合的合成因子暴露。
- 约束：
  - 行业权重 = 基准行业权重
  - 市值中性（以对数市值加权）
  - 个股权重偏离上限：分别测试 0.5%, 1%, 1.5%, 2%
  - 双边换手率 ≤ 60%（报告中为 60%，但可调整）
- 交易成本：单边 **万分之 7.5**（7.5 bps）。
- 绩效指标：年化收益率、波动率、夏普比率、最大回撤、年化超额收益、信息比率、Calmar 比率等。

## 7. 预期结果（基于原报告数据）

### 7.1 全 A 股（v2 vs v1）

- RankIC 均值：v1 9.72% → v2 **10.76%**
- ICIR：1.00 → **1.15**
- 中证500 增强策略年化超额：17.17% → **19.09%**，信息比率 2.73 → **3.13**

### 7.2 中证800 成分股（v2 vs v1）

- RankIC 均值：8.37% → **8.63%**
- ICIR：0.73 → **0.75**
- 中证800 增强策略年化超额：6.19% → **7.84%**，信息比率 1.65 → **2.00**

### 7.3 中证500 成分股（v3 vs v2）

- RankIC 均值：9.05% → **9.70%**
- ICIR：0.89 → **1.00**
- 中证500 增强策略年化超额：9.40% → **9.75%**，信息比率 2.19 → **2.30**

> 注：以上为原报告无成本或千分之二成本下结果，本文档修改成本为万分之 7.5（7.5 bps），收益绝对值会下降，但相对比较优势应保持。

## 8. 代码实现要点（基于 v2 和 v3）

### 8.1 数据生成器

- 图片尺寸：`(15, 30)`，包含原 9 个特征 + 6 个比率。
- 标签：未来 10 天收益率（标准化）。
- 采样：每隔两天取一个截面，降低相关。

### 8.2 自定义特征提取层

- 可重用 v1 的实现，但注意 v3 有两层，d=10 和 d=5，stride 相应调整。
- 层输出形状：
  - 对每个算子，输出特征图尺寸为 `(num_pairs_or_features, num_windows)`，其中 `num_windows = (30 - d) // stride + 1`。
  - 所有算子的输出在特征维度上拼接，再经 BN。

### 8.3 LSTM/GRU 层（关键差异）

- v2：将特征提取层的输出（形状 `(batch, num_windows, feature_dim)`）输入一个 **LSTM** 层，`time_step = num_windows`（若 stride=10, d=10，则 num_windows=3），输出 30 维向量。
- v3：使用 **GRU** 替换 LSTM，并增加第二个 GRU 层（`time_step=6`，对应窗口可能不同，需根据具体设计调整）。注意 v3 有两个特征提取层，对应的时间维度不同，因此两个 GRU 分别处理不同窗口的特征。

### 8.4 网络构建（v2 示例）

```python
from tensorflow.keras import layers, Model

input_img = Input(shape=(15, 30))
# 特征提取层（同 v1，但输入15维）
extracted = extract_features(input_img)  # 假设返回 (batch, num_windows, feat_dim)
extracted = BatchNormalization()(extracted)

# LSTM 层
lstm_out = layers.LSTM(30, return_sequences=False)(extracted)  # time_step = num_windows
lstm_out = BatchNormalization()(lstm_out)

# 输出层
output = layers.Dense(1, activation='linear')(lstm_out)

model = Model(inputs=input_img, outputs=output)
model.compile(optimizer=Adam(0.0001), loss='mse')
```

### 8.5 v3 注意事项

- 特征提取层分为 d=10 和 d=5 两组，分别产生不同时间步长的特征。
- 对 d=10 的特征（time_step=3）使用第一个 GRU，对 d=5 的特征（time_step=6）使用第二个 GRU，然后拼接或相加后接输出层。

### 8.6 滚动训练与预测

- 循环：每半年更新训练区间，重新训练 10 个模型。
- 每个模型早停，保存最佳权重。
- 预测时取 10 个模型预测均值作为合成因子。

## 9. 与“遗传规划+随机森林”对比

原报告还对两种方法做了优劣对比（图表 14），要点如下：


|        | 遗传规划+随机森林（传统 ML）                  | AlphaNet（深度学习）                                       |
| ------ | --------------------------------- | ---------------------------------------------------- |
| **优点** | 1. 流程分步，可解释性强 2. 因子表达式明确 3. 函数库丰富 | 1. 端到端学习，目标一致 2. 无需维护因子池，省去单因子测试等 3. 灵活适应不同股票池/周期/频率 |
| **缺点** | 1. 流程复杂，人工干预多 2. 不端到端，更换场景需重新挖掘因子 | 1. 可解释性较差 2. 算子库尚不如遗传规划全面                            |


复现时可结合两者优点：AlphaNet 负责端到端预测，遗传规划用于发现新特征算子（可考虑后期嵌入）。

## 10. 风险提示

- **过拟合**：深度网络、滚动训练、10 次重复可减轻，但仍需警惕样本内过拟合。
- **随机性**：不同随机种子可能差异较大，必须重复多次取平均。
- **市场环境变化**：2019 年后 v1 表现下滑，说明模型可能依赖特定市场状态，升级后仍需持续监控。
- **交易成本**：单边万分之 7.5（7.5 bps），与仓库其余因子回测一致。勿与千分之 7.5（0.75%）混淆。
- **计算资源**：v3 参数量约 5.4 万，且双层特征提取+双 GRU，训练成本高于 v2，建议使用 GPU。

---

## 11. 总结与后续方向

- v2 通过增加比率特征、引入 LSTM 和调整训练/验证比例，显著提升了全 A 股和中证 1000 的选股效果。
- v3 在中证 500 上较 v2 有温和提升，验证了多尺度特征提取（回看 5 天和 10 天）的有效性，但计算成本增加。
- 本复现指南采用与仓库一致的测试条件（10 层、超额收益、单边成本万分之 7.5），可更公允地评估因子质量，并与现有因子库（如 L2 因子）对比。
- 后续可考虑将 AlphaNet 输出的合成因子作为独立因子纳入多因子体系，或与切割算子模块结合，共同构建 AI 选股策略。
