> 研究对象：`reversal_20d` · `amount_to_volatility_20d` · `amount_stability_20d`

> 研究标准：经济逻辑 → 统计显著性 → 风格污染 → 未来函数/过拟合 → 可投资性（非仅看 Sharpe）

# 因子名称：reversal_20d

## 1. 经济逻辑解释

**短期过度反应**：过去 20 个交易日涨幅过大的股票，往往被趋势追逐与注意力驱动推高；过去 20 日跌幅过大的股票则常被过度抛售。行为偏差（外推偏差、处置效应）叠加流动性提供者的补偿，形成月频附近的反转溢价。

**A 股特征**：反转在小盘、高换手池更强——信息噪声大、散户占比高、涨跌停与情绪冲击更频繁。大盘蓝筹中同一机制仍存在，但幅度明显收敛。

**机制边界**：这是「价格路径」上的均值回归，不是基本面质量，也不是成交稳定性。若不中性化，极易与小市值、高波动风格缠在一起。

## 2. 数学公式

记过去 20 日累计收益：

\[
R_{20}=\frac{P_t}{P_{t-20}}-1
\]

原始因子（已取反，高值 = 过去跌得多）：

\[
f_{\mathrm{rev}}=-R_{20}
\]

每日截面 Z-score 得 \(z_{\mathrm{rev}}\)。回测中 `direction = +1`：做多高 \(f\)（前期弱势股），做空低 \(f\)（前期强势股）。

## 3. 代码实现

```python
@register_factor("reversal_20d")
def factor_reversal_20d(cache: FactorDataCache) -> pd.DataFrame:
    return -cache.get("ret_20d")  # ret_20d = close/close.shift(20)-1
```

生产流水线：`align_signal(..., shift=1)` → `cs_zscore` → 组合加权。无未来函数。

## 4. 为什么这个因子好？好在哪里？

- **统计显著**：全市场 Rank IC **4.39%**，ICIR **4.13**，H-L Sharpe **2.44**，符号在 CSI300/500/1000/ALL 一致为正。
- **机制经典、可解释**：不依赖复杂交互项，参数只有一个回看窗口，过拟合空间相对可控。
- **小票信息更强**：CSI1000 IC 3.80%、Sharpe 1.75，显著高于 CSI300（IC 1.63%、Sharpe 0.23）——符合 A 股反转的市值梯度。

## 5. 风险敞口

- **市值暴露（核心风险）**：小票强、大票弱本身就是市值污染信号。风格切换时可能「反转失效 + 小盘回撤」双杀。
- **波动率纠缠**：高波股更易出现极端 20 日收益，反转多空两端都偏高波。
- **单调性不完美**：十分组收益前半段上升、后半段（Q6–Q10）扁平，mono ≈ **0.67**。极端输家贡献大量 alpha，中间赢家区分度弱。
- **换手偏高**：全市场 H-L 日均换手约 **0.94**，成本敏感；净收益需单独扣费评估。
- **趋势牛回撤**：单边结构性牛市中反转空头承压（与 D5 类似的 regime 风险）。

## 6. 分指数验证结果

| 股票池 | IC 均值 | ICIR | H-L Sharpe | 年化 H-L | 换手 | 备注 |
|--------|---------|------|------------|----------|------|------|
| 沪深 300 | 1.63% | 1.15 | 0.23 | 6.6% | 0.88 | 大盘反转弱，接近风格噪声边界 |
| 中证 500 | 2.54% | 2.05 | 0.60 | 15.1% | 0.90 | 中盘开始稳定 |
| 中证 1000 | 3.80% | 3.42 | 1.75 | 41.3% | 0.93 | 核心有效池 |
| 全市场 | 4.39% | 4.13 | 2.44 | 57.5% | 0.94 | 含小票后 IC/Sharpe 抬升 |

> **误区提示**：跨池 IC 梯度陡峭 ≠「因子更强」，更可能是 **市值暴露被放大**。入库前必须做 `factor ~ log_mktcap + vol + industry` 残差检验。

## 7. 怎么用？

- **推荐**：残差反转（控制市值、行业、20d 波动）后再进组合；或使用库内 `residual_reversal_20d` / `low_attention_reversal_20d` 作为更干净变体。
- **不推荐**：与 `amount_to_volatility_20d` 等权堆叠——边际信息重叠。
- **定位**：行为维的基础层，权重不宜过高；换手高，适合中低频再平衡或与低换手因子（如 D1）对冲换手。

# 因子名称：amount_to_volatility_20d

## 1. 经济逻辑解释

**单位风险上的成交参与度**：用「20 日均成交额 / 20 日收益波动率」衡量：同样波动水平下，成交额异常偏高，往往对应情绪拥挤、短线资金集中进出；成交额相对波动偏低，则更接近冷清、关注度不足的状态。

**回测方向**：原始值越高 → 后续收益越差（`direction = -1`）。经济含义是 **做空「高成交/高参与度相对波动」的拥挤标的**，做多相对冷清标的——仍属反拥挤 / 情绪均值回归，而非「流动性溢价」的正向定价。

**与反转的关系**：大涨常伴随放量，高 \(R_{20}\) 与高 amount、高 vol 同时出现，使本因子与 `reversal_20d` 在截面上容易同向捕捉「过热后回落」。

## 2. 数学公式

\[
\overline{A}_{20}=\mathrm{mean}(A_{t-19},\ldots,A_t),\quad
\sigma_{20}=\mathrm{std}(r_{t-19},\ldots,r_t)
\]

\[
f_{\mathrm{a2v}}=\frac{\overline{A}_{20}}{\sigma_{20}}
\]

交易信号取负向：

\[
\mathrm{signal}=-\,z(f_{\mathrm{a2v}})
\]

（实现上保留原始 \(f\)，回测引擎用 `direction=-1` 翻转多空。）

## 3. 代码实现

```python
@register_factor("amount_to_volatility_20d")
def factor_amount_to_volatility_20d(cache: FactorDataCache) -> pd.DataFrame:
    amt = cache.get("amount_mean_20d")
    vol = cache.get("volatility_20d")
    return amt / vol.replace(0, np.nan)
```

同样 `shift(1)`，无未来函数。注意：分子是成交额**水平**，对大市值天然偏大，存在规模偏置。

## 4. 为什么这个因子好？好在哪里？

- **方向清晰、分组极单调**：按交易方向重排后十分组 mono = **1.00**，Q 低→高收益严格递增，适合线性多空。
- **全市场 IC 显著**：Rank IC **−2.94%**，ICIR **−3.04**，H-L Sharpe **1.57**。
- **换手极低**：全市场 H-L 换手约 **0.21**，在三者中成本压力最小——若机制独立，会是很好的低换手卫星。

## 5. 风险敞口

- **大盘失效**：CSI300 IC 仅 **+0.47%**、Sharpe **0.19**，信息几乎消失；有效性集中在中小盘。
- **构造偏置**：\(\overline{A}/\sigma\) 未对市值或平均成交额做残差，部分「低因子值」只是小票/低流动性，而非真正的「低拥挤」。
- **与反转共线（关键误区）**：同属情绪回落链条；D2 density 中相对 risk rep 的相关约 0.05–0.27，但对 **价格反转** 的增量未在库内做正式 FM 回归。在未证明残差 IC 前，不应计为独立 alpha 维。
- **命名易误导**：易被理解成「高流动性更好」；实际交易方向是做空高 amount/vol。

## 6. 分指数验证结果

| 股票池 | IC 均值 | ICIR | H-L Sharpe | 年化 H-L | 换手 | 备注 |
|--------|---------|------|------------|----------|------|------|
| 沪深 300 | +0.47% | 0.57 | 0.19 | 2.9% | 0.21 | 基本失效 |
| 中证 500 | −1.60% | −1.57 | 0.65 | 13.7% | 0.27 | 开始有效 |
| 中证 1000 | −2.46% | −2.49 | 1.20 | 25.4% | 0.30 | 中小盘驱动 |
| 全市场 | −2.94% | −3.04 | 1.57 | 30.1% | 0.21 | 单调性满分（交易方向） |

> universe_stability 仅 **0.07**（`robust_alpha_ranking`），跨池一致性差，生产分偏低。

## 7. 怎么用？

- **研究定位**：作为反转/拥挤的 **诊断变量** 或稳健性对照，而非独立 base。
- **若坚持使用**：先对 \(\log(\overline{A}_{20})\)、\(\sigma_{20}\)、\(\log\mathrm{mktcap}\) 回归取残差，再检验相对 `reversal_20d` 的增量 IC；通不过则淘汰。
- **组合**：不要与 `reversal_20d` 同时高权重；二选一或只保留残差版中更干净的一个。

# 因子名称：amount_stability_20d

## 1. 经济逻辑解释

**成交稳定性 ≠ 成交水平**：用成交额变异系数 \(\mathrm{CV}=\sigma(A)/\mu(A)\) 衡量交易活跃度的路径平滑程度。CV 低 → 成交节奏稳定，多为机构持续配置、信息冲击小；CV 高 → 脉冲式放量/缩量，常伴随游资炒作与流动性冲击，后续收益偏负。

**相对 D1 的关系**：D1（`low_vol_liquidity_quality_60d`）= 低波动 + 低成交 CV。本因子是 D1 的 **流动性质量半边**（20d 窗口、无波动项）。因此单独回测可以很强，但在 D1 已入选 base 后，增量信息有限——库内已判定 **redundant to D1**（504d 相关 **0.79**）。

## 2. 数学公式

\[
\mathrm{CV}_{20}=\frac{\mathrm{std}(A_{t-19},\ldots,A_t)}{\mathrm{mean}(A_{t-19},\ldots,A_t)}
\]

\[
f_{\mathrm{stab}}=-\mathrm{CV}_{20}
\]

高值 = 更稳定。截面 Z-score 后 `direction = +1`。

用 CV 而非 \(\sigma(A)\)，避免「大票成交额绝对值标准差更大」的尺度陷阱。

## 3. 代码实现

```python
# cache: amount_cv_20d = rolling_std(amount,20) / rolling_mean(amount,20)
@register_factor("amount_stability_20d")
def factor_amount_stability_20d(cache: FactorDataCache) -> pd.DataFrame:
    return -cache.get("amount_cv_20d")
```

`shift(1)` 对齐；confirmation 样本十分组收益严格单调。

## 4. 为什么这个因子好？好在哪里？

- **确认样本极强**（1455d，ALL）：IC **4.05%**，ICIR **8.64**，H-L Sharpe **4.58**，mono **1.00**，IC 胜率 72%。
- **跨池全覆盖**：CSI300→1000 符号一致，IC 随市值下沉抬升但仍在大盘显著（CSI300 IC 2.06%、ICIR 2.50）。
- **换手中等**：约 **0.64**，优于纯反转（0.94），劣于 amount/vol（0.21）。
- **IC 衰减慢**：1d→20d 远期 IC 不降反升（0.033→0.050），偏慢变量，适合作为质量/过滤层。

## 5. 风险敞口

- **对 D1 冗余（已坐实）**：density 中 `ic_after_d1` 接近 0、相关 0.79，分类 **redundant**。高 solo Sharpe 很大程度是「潜伏的 D1」。
- **流动性水平污染**：稳定成交与高平均成交、大市值相关；需与 `amount_20d_mean`、市值做残差（库内有 `liquidity_amount_residual_20d` 方向）。
- **不是尾部专用**：与用户示例中「仅极端组有效」的担忧相反——本样本十分组 **全程单调**，可作排序因子；但在已有 D1 时再作排序因子会重复暴露。
- **牛市拥挤期**：稳定成交的「慢牛股」可能阶段性跑输高波动题材，IC 很少转负但相对收益会弱。

## 6. 分指数验证结果（confirmation 1455d）

| 股票池 | IC 均值 | ICIR | H-L Sharpe | 年化 H-L | 换手 | 单调性 |
|--------|---------|------|------------|----------|------|--------|
| 沪深 300 | 2.06% | 2.50 | 0.99 | 16.1% | 0.66 | 极好 |
| 中证 500 | 2.60% | 4.06 | 1.65 | 22.4% | 0.65 | 极好 |
| 中证 1000 | 3.43% | 6.46 | 2.95 | 34.6% | 0.65 | 极好 |
| 全市场 | 4.05% | 8.64 | 4.58 | 46.5% | 0.64 | **1.00** |

> 这是三者中 **统计画像最漂亮** 的因子；问题不在「好不好」，而在「相对 D1 还有没有新信息」。

## 7. 怎么用？

- **有 D1 在库**：不要再给 `amount_stability_20d` 独立权重。可作 **硬过滤**（剔除 CV 最高的 10–20%），或仅用于诊断流动性质量。
- **无 D1 / 研究对照**：可作单因子或质量层；优先测试 `log` 成交 CV、10d/60d family，以及市值+成交额水平中性化残差。
- **与反转搭配**：机制互补（稳定 vs 路径反转），相关性预期低于 amount/vol 与反转；但仍需先减掉 D1 重叠再谈「第三维」。

# 交叉自查（按「量化因子研究误区与方向」）

## 一、构造透明度与未来函数

| 检查项 | 结论 |
|--------|------|
| 公式是否唯一确定 | 是；三者均在 `factor_formulas.py` 注册 |
| 是否 `shift(1)` | 是；`align_signal` 统一 T+1 |
| 是否用到未来数据 | 否 |
| 命名是否误导 | `amount_to_volatility` 易被理解成正向流动性溢价，实际 **做空高值** |

## 二、经济直觉是否独立

三者共享 **「情绪/拥挤 → 回落」** 主线：

- 反转：价格过度反应  
- amount/vol：成交相对波动的拥挤  
- amount_stability：成交路径不稳 = 炒作型流动性  

只有 `amount_stability` 把「水平」和「稳定性」拆开，机制叙述最干净；但它与生产 D1 重叠。

## 三、风格污染清单（入库前必做）

建议统一中性化回归：

\[
f \sim \log\mathrm{mktcap}+\sigma_{20}+\overline{A}_{20}+\mathrm{Industry}
\]

| 因子 | 主要污染源 | 残差后预期 |
|------|------------|------------|
| reversal | 市值、波动 | IC 下降但仍应显著，否则只是小盘 |
| amount_to_volatility | 成交额水平、市值、波动 | 残差可能大幅变弱 |
| amount_stability | 市值、成交水平；相对 D1 | 对 D1 残差后 IC 应接近消失（已有 density 证据） |

## 四、过拟合与参数族

- 窗口均为 20d：需补 **10d / 60d** family；`amount_stability` 已有 60d 引擎变体可对照。
- `amount_to_volatility` 生产分接近 0，跨池不稳，优先视为 fragile。
- 反转在 CSI300 过弱：避免用全市场 Sharpe 掩盖大盘失效。

## 五、因子间增量（信息论）

| 关系 | 证据 | 动作 |
|------|------|------|
| reversal ↔ amount_to_volatility | 同向情绪回落；后者大盘失效 | 合并或淘汰后者 |
| amount_stability ↔ D1 | corr≈0.79，density=redundant | 不进 Base3；过滤器用 |
| reversal ↔ amount_stability | 机制不同（路径 vs 成交稳定） | 可测 FM 增量，但先各自中性化 |

## 六、可投资性快照

| 因子 | 换手 | 容量直觉 | 净成本压力 |
|------|------|----------|------------|
| reversal_20d | ~0.94 | 小票依赖，容量一般 | 高 |
| amount_to_volatility_20d | ~0.21 | 偏中小盘，方向依赖空头 | 低，但 alpha 纯度存疑 |
| amount_stability_20d | ~0.64 | 偏向稳定成交票，实盘友好 | 中；与 D1 重复暴露时无增益 |

---

# 总结与入库建议

1. **`reversal_20d`**：有效但「脏」。保留为行为反转候选，**中性化后**再进增强层；监控大盘失效与高换手。  
2. **`amount_to_volatility_20d`**：回测单调漂亮、换手低，但大盘失效 + 与反转同逻辑 → **默认不入库**，除非残差增量检验通过。  
3. **`amount_stability_20d`**：单因子画像接近机构级质量因子，但在本项目中是 **D1 的冗余表达** → 维持 `frozen_candidate_pool` 的 rejected 结论；实盘用 D1，本因子最多做流动性尾部过滤。

按上述标准走完「中性化 → 相关/FM 增量 → 参数族 → 用途重定义」后，三者才能从「回测好看的信号」变成「可审计的库模块」。当前最需要补的实证不是再刷 Sharpe，而是 **残差 IC 与两两增量检验**。
